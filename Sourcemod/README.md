# 🧩 SourceMod

SourceMod adds scripting support, admin tools, and plugin management to your Counter-Strike: Source server. Install it after [Metamod:Source](../Metamod/README.md).

## 📥 Installation

1. Copy or upload the `addons` and `cfg` folders into your `cstrike` directory.
2. Restart the server.
3. Open the server console and run:

```text
sm version
```
