# 🧱 Metamod Plugins

This directory contains optional plugins that load through [Metamod:Source](../Metamod/README.md).

## 📋 Before You Install

- Make sure Metamod:Source is already installed and working.
- Read the README inside the plugin folder before copying files.
- Restart the server after each plugin install or update.

## 📦 Available Plugins

| Plugin | Description |
| --- | --- |
| [BufferFix](BufferFix/README.md) | Linux compatibility fix for newer distributions. |
| [Stripper](Stripper/README.md) | Map entity editing and cleanup utility. |

## ✅ Verification

Use the server console to confirm Metamod is active:

```text
meta version
```

Individual plugins may expose their own commands or require extra configuration steps.
