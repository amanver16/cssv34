# 🧱 Stripper

Stripper is a Metamod plugin used to add, edit, or remove map entities at runtime. It is commonly used to clean up maps, remove fog or decals, and apply custom entity changes without recompiling the map.

## 📥 Installation

1. Copy the `addons` folder into your `cstrike` directory.
2. Add the following line to `cstrike/addons/metamod/metaplugins.ini`:

```text
addons/stripper/bin/stripper_mm
```

3. Restart the server.

## ✅ Verification

After restart, confirm Metamod loads normally and review your Stripper configuration files if you expect custom entity edits to apply.
