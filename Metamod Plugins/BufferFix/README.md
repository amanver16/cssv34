# 🩹 BufferFix

BufferFix is a Metamod plugin intended for Linux servers that fail to start correctly on newer distributions. It is mainly useful when the server hangs with messages such as `Unknown Command` or similar startup issues.

## ⚠️ When To Use It

Install this plugin only if your CSS v34 server has compatibility problems on a modern Linux system. If the server already runs normally, you do not need BufferFix.

## 📥 Installation

1. Copy the `addons` folder into your `cstrike` directory.
2. Restart the server.

## ✅ Verification

After restart, confirm the server now finishes startup normally and stays responsive in the console.
