# 🕶 Host Manager

Host Manager is a SourceMod extension that allows server administrators to hide player SteamIDs from host output. This can help reduce unwanted exposure of player identifiers.

## 📥 Installation

1. Extract and copy the `addons` folder into your `cstrike` directory.
2. Restart the server.

## ✅ Verification

Run the following command in the server console:

```text
sm exts list
```

Confirm that `Host Manager` appears in the loaded extensions list.
