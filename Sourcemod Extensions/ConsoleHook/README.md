# 🖥 ConsoleHook

ConsoleHook is a SourceMod extension used by certain plugins that need extra console-printing functionality.

## 📥 Installation

1. Extract and copy the `addons` folder into your `cstrike` directory.
2. Restart the server.

## ✅ Verification

Run the following command in the server console:

```text
sm exts list
```

Confirm that `ConsoleHook` appears in the loaded extensions list.
