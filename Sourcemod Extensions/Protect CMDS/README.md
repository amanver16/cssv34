# 🕶 Protect CMDS

	Protect CMDS is a SourceMod extension that provides protection against multiple server exploits, it makes the server VAC secure and can block console commands and many more features.

## 📥 Installation

1. Extract and copy the `addons` folder into your `cstrike` directory.
2. Restart the server.

## ✅ Verification

Run the following command in the server console:

```text
sm exts list
```

Confirm that `Protect CMDS` appears in the loaded extensions list.
