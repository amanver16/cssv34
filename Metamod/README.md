# 🔌 Metamod:Source

Metamod:Source is the base plugin loader for Source engine servers. Install it before using any package from [Metamod Plugins](../Metamod%20Plugins/README.md).

## 📥 Installation

1. Copy or upload the `addons` folder into your `cstrike` directory.
2. Restart the server.
3. Open the server console and run:

```text
meta version
```

## ✅ Expected Output

You should see output similar to:


## ➡️ Next Step

If Metamod loads correctly, you can proceed to [SourceMod](../Sourcemod/README.md) or install a package from [Metamod Plugins](../Metamod%20Plugins/README.md).
